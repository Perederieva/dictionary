# Словничок: інструкція з розгортання

Як це влаштовано: **без реєстрації і паролів**. Ти відкриваєш сайт, натискаєш «Створити мій словничок» і отримуєш особисте посилання (довгий випадковий ключ після `#`). Окреме посилання даєш вчителю. Це як Google Sheets «доступ за посиланням».

Складається з двох частин:
- **Supabase**: безкоштовна база даних. Доступ до таблиць закритий повністю, працюють лише кілька функцій, які перевіряють ключ.
- **Хостинг сайту**: GitHub Pages або Cloudflare (на вибір, див. крок 4).

Файли:
- `index.html`
- `css/styles.css`
- `js/`: код (`config.js`: сюди вставиш дані Supabase, `api.js`: запити, `store.js`: стан і збереження, `learn.js`: навчання, `lists.js`: списки слів, `access.js`: посилання, `teacher.js`: вигляд вчителя, `text.js`: перевірка відповідей, `starter.js`: стартові слова, `util.js`: дрібні функції, `main.js`: запуск)
- `supabase/schema.sql`: таблиці й функції

## Оновлення: типи й теми

Якщо сайт уже розгорнутий, онови так:
1. У Supabase → SQL Editor → новий запит: встав весь вміст `supabase/migration_002_kind_tags.sql` → **Run**. Він додає колонки, не чіпаючи твої слова.
2. Скопіюй у папку проєкту всі нові файли, **крім `js/config.js`** (він у тебе вже заповнений).
3. `git add . && git commit -m "Types and tags" && git push`, через хвилину онови сторінку (Cmd+Shift+R).

Нова база (з нуля): достатньо `supabase/schema.sql`, міграція не потрібна.

## 1. Supabase

1. На supabase.com зареєструйся (можна через GitHub) і створи проєкт (**New project**): назва `slovnychok`, придумай Database password і збережи, регіон ближчий до тебе. Дочекайся створення (1-2 хв).
2. Зліва **SQL Editor** → **New query**. Встав весь вміст `supabase/schema.sql` → **Run**. Має бути «Success».
3. **Project Settings → API** (або кнопка **Connect**). Скопіюй:
   - **Project URL** (виглядає як `https://abcd.supabase.co`)
   - **Publishable key** (у старому інтерфейсі це `anon` key)

4. **Закрий створення словників від чужих.** У тому ж SQL Editor виконай (придумай свою довгу фразу, мінімум 4 слова, і збережи її):

```sql
update app.config set create_code_hash = app.key_hash('твоя довга фраза-код');
```

Без цього коду ніхто не зможе створити словник, навіть якщо знайде адресу сайту. Після того, як ти створиш свій словник (крок 5), виконай:

```sql
update app.config set create_code_hash = null;
```

і створення нових словників закриється повністю. Знадобиться знову: поверни перший запит.

Налаштовувати Authentication не потрібно, нічого вимикати теж.

## 2. js/config.js

Відкрий `js/config.js` у редакторі й заміни обидва значення:

```js
export const CONFIG = {
  SUPABASE_URL: 'https://abcd.supabase.co',
  SUPABASE_KEY: 'sb_publishable_...'
};
```

Цей ключ публічний за задумом. Ніколи не вставляй сюди `service_role` або secret key.

## 3. Локальна перевірка (рекомендую)

У папці проєкту виконай `python3 -m http.server 8000` і відкрий http://localhost:8000. Введи код створення і натисни «Створити мій словничок». Подвійним кліком по `index.html` не відкриється: модулям потрібен сервер.

## 4. Хостинг

**Варіант A. GitHub Pages (простіше).** Репозиторій має бути **публічним**: на безкоштовному плані Pages для приватних репозиторіїв недоступний. Це безпечно: у коді немає жодних даних, лише публічний ключ. Дані захищені твоїм посиланням.
1. github.com → **New repository** → `slovnychok`, **Public**.
2. **Add file → Upload files**: перетягни `index.html` і папки `css`, `js`, `supabase`. **Commit changes**.
3. **Settings → Pages**: Source = **Deploy from branch**, Branch = `main`, `/ (root)` → **Save**.
4. Через 1-2 хвилини адреса буде `https://<твій-нік>.github.io/slovnychok/`.

**Варіант B. Cloudflare (код можна не публікувати).** У dashboard Cloudflare: **Workers & Pages → Create** і далі пряме завантаження готової папки (Direct upload / Upload assets) без GitHub. Можна також підключити приватний репозиторій GitHub. Назви кнопок у Cloudflare іноді змінюються, шукай «upload your static files». Безкоштовний план достатній. Адреса матиме вигляд `https://<назва>.pages.dev`.

Сама адреса сайту публічна в обох варіантах, але без ключа вона показує лише поле «Код створення».

## 5. Як користуватися

1. Відкрий сайт → введи код створення → **Створити мій словничок** → скопіюй і **збережи** посилання (у нотатки чи пароль-менеджер). Його ж можна відкрити з телефона.
2. У вкладці **Доступ** є «Посилання для вчителя». Надішли його вчителю.
3. Вчитель відкриває його: бачить серію, скільки слів вивчено сьогодні, слабкі слова, усі слова з рівнями. Може додавати слова (по одному чи списком) і видаляти лише ті, що додав сам. Твій прогрес змінити не може.
4. Якщо посилання вчителя потрапило не туди, натисни **Створити нове посилання для вчителя**: старе перестане працювати одразу.

## 6. Безпека: чесно

Що захищено:
- До таблиць у базі немає прямого доступу ні з сайту, ні з інтернету. Лише 8 функцій, і кожна вимагає ключа.
- Ключ довгий (256 біт), підібрати його неможливо. У базі лежить лише його хеш.
- Вчитель має окремий ключ з меншими правами (не пише прогрес і налаштування).
- Ключ у посиланні стоїть після `#`: він не потрапляє ні на сервер сайту, ні в логи, ні в заголовок Referer.
- Сторінка має політику CSP (дозволяє лише власні скрипти й запити до Supabase) і `noindex`.
- Сайт не використовує жодних сторонніх скриптів.

Що це не гарантує:
- **Хто має посилання, той має доступ**, як у Google Sheets. Не публікуй його в чатах із чужими людьми. Посилання вчителя можна відкликати, своє: ні (воно і є твій словник).
- **Загубила посилання й очистила браузер: словник не відновити.** Збережи його.
- Адміністратор проєкту Supabase (тобто ти) бачить усю базу. Посилання вчителя зберігається там у відкритому вигляді, щоб ти могла його переглянути у вкладці «Доступ».
- Створення словників закрите кодом (крок 1.4), а після твого першого словника його можна закрити повністю. Код не має обмеження спроб, тож роби його довгим.
- Я не гарантую відсутності помилок. Код перевірено автоматично (повний цикл на реальному Postgres і в браузері Chromium), але не незалежним аудитом.

## 7. Важливо знати

- Безкоштовний проєкт Supabase призупиняється після тижня без активності. Якщо сайт перестав завантажуватися, зайди в dashboard і натисни **Restore project**. Дані зберігаються.
- Дані окремого Claude-артефакту «Словничок» сюди не переносяться. Слова можна перенести списком: **Слова → Додати списком**.

## 8. Якщо щось не так

| Симптом | Що робити |
|---|---|
| «Сайт ще не підключено до Supabase» | Не заповнено `js/config.js` або він не завантажений |
| «Невірний код створення» | Введено не ту фразу, що в SQL, або створення закрите (`create_code_hash = null`) |
| «База ще не налаштована» | Не виконано `schema.sql` |
| «Це посилання недійсне» | Посилання скопійоване не повністю, або вчителю створили нове |
| Порожня сторінка / помилка в консолі | Відкрито через `file://`; запусти `python3 -m http.server` |
| Не завантажуються шрифти | Це лише оформлення, сайт працюватиме |
| GitHub Pages: 404 | Зачекай 2 хв, перевір Settings → Pages і що є `index.html` в корені |
